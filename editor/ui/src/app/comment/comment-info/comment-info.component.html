Alte und neue Kommentare

Hier können Sie Kommentare zu den Noten eingeben. Diese bestehen aus 4 Teilen:

  • Einem Kommentar
  • Der Emendation
  • Einer Zeile
  • Einem Gitter

Der Kommentar, die Emendation und die Zeile bilden den alten Teil. Die Emendation und das Gitter bilden den neuen Teil.

Für neue Kommentare nutzen Sie also bitte nur die Emendation und das Gitter. Die alten Kommentarteile können bestehen bleiben, müssen also nicht entfernt werden. Der Endnutzer auf der Corpus-Monodicum Webseite sieht den alten Teil nur, wenn ein neuer nicht existiert.

Aufbau neuer Kommentar

Der neue Kommentar besteht aus einer Reihe an (möglicherweise geschachtelten) Elementen. Die möglichen Elemente sind:

  • Ein Gitter, um andere Elemente anzuorden
  • Ein Text, bei dem Sie Freitext eingeben können
  • Einer eckigen Klammer
  • Einer Notenzeile
Beispiel für einen neuen Kommentar

Wenn Sie zum Beispiel einen Kommentar erstellen wollen, der Links die original Noten hat, dann eine Klammer und dann eine korrigierte Notenzeile, dann können Sie das so machen:

  1. Klicken Sie auf "Gitter hinzufügen".
  2. Weil Sie nun 3 Unterlemente anordnen wollen, klicken Sie auf "Gitter".
  3. Fügen Sie dem Gitter dann über den "+"-Button drei neue Spalten hinzu.
  4. Klicken Sie in der ersten Spalte auf "Noten". Die Originalzeile wird automatisch eingefügt.
  5. Klicken Sie in der zweiten Spalte auf Klammer.
  6. Klicken Sie in der dritten Spalte auf "Noten".
  7. Die rechte Notenzeile können Sie nun nach belieben editieren.

Fertig. Sie könnten die Kommentardialog nun schließen und das Dokument speichern.

Textformatierung

In Textblöcken können Sie nicht nur normalen Text eingeben, sondern mit einer Markdown-ähnlichen Syntax ihren Text auch formatieren. Der Text den Sie eingeben wird dem Endnutzer auf der veröffentlichten Seite standardmäßig in Italics angezeigt. Sie können aber auch andere Formatierungen wählen:

  • Normaler (nicht italic) Text: Packen Sie den Text in (( und )) ein.
  • Kapitälchen Text: Packen Sie den Text in [[ und ]] ein.
  • Text mit einem Ramen: Packen Sie den Text in {{ und }} ein.
